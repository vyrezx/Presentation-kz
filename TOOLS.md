# Инструменты

| Инструмент | Применение |
|---|---|
| FFmpeg, FFprobe и Pillow | 0,5-секундные выборки из трёх роликов, контактные листы, локальные WebP |
| Sites, frontend-design | Структура проекта, постановка интерфейса |
| GSAP Core, Timeline и ScrollTrigger Skills | Прокрутка, синхронизация слоёв, композиция и настройки снижения движения |
| Context7 MCP | Документация GSAP, SplitText и ScrollTrigger |
| Web Search MCP | Исторические источники, лицензии, проектные референсы |
| ImageGen | Гравюрная панорама входа и городские фоны |
| GSAP, SplitText, ScrollTrigger | Посимвольный заголовок, маски, движение виртуальной камеры и черчение маршрутов |
| SVG, CSS 3D, Pointer Events | Карты, 2.5D, вращение документов, панорамирование и инерция |
| Vite и npm | Локальная разработка, сборка и фиксация версий зависимостей |
| Playwright и Chromium | Desktop и mobile, управление с клавиатуры и через указатель, диалоги, тест и сборка |
| Git, GitHub CLI, GitHub MCP | Проверка доступных репозиториев и публикация исходников |
| Vercel MCP, Vercel Deployments skill | Проверка доступа к размещению и конфигурация Vite |

## Изученные примеры

- [Codrops Creative Hub](https://tympanus.net/codrops/hub/tutorials/) и [GSAP Highlights](https://tympanus.net/codrops/hub/gsap-highlights/). Синхронизация движения сцены, траектории SVG и маски при прокрутке.
- [GSAP Showcase](https://gsap.com/showcase/), [Awwwards](https://www.awwwards.com/) и [CSS Design Awards](https://www.cssdesignawards.com/). Редакционная иерархия, крупные самостоятельные сцены и экспозиционный ритм.
- [Three.js Examples](https://threejs.org/examples/), [React Three Fiber Examples](https://github.com/pmndrs/react-three-fiber/blob/master/docs/getting-started/examples.mdx) и [Showcase Images](https://github.com/cortiz2894/showcase-images). Камера и независимые планы. В выставке применены CSS-перспектива и SVG.
- [Три приложенных видеореференса](REFERENCE_ANALYSIS.md). Принципы графики и конкретные таймкоды.
