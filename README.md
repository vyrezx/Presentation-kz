# Осман империясының ыдырауы

Н. Алдабектің 8-сыныпқа арналған «Дүниежүзі тарихы» оқулығының §10 тақырыбы бойынша қазақ тіліндегі 12 бөлімді интерактивті көрме.

## Іске қосу

Node.js 22.12 немесе одан жаңа нұсқа қажет.

```sh
npm ci
npm run dev
```

Vite терминалда мекенжайды көрсетеді. Жинақталған нұсқаны тексеру үшін `npm run build` және `npm run preview` пәрмендерін іске қосыңыз. ZIP ішіндегі `dist/` бумасын статикалық серверден де ашуға болады, мысалы `python -m http.server 8080 --directory dist`.

`vercel.json` Vercel үшін Vite жинағын көрсетеді. Құпия кілттер мен сервер қажет емес.

## Жоба құрылымы

- `src/history.js` — мәтін, хронология, портреттер, салыстыру және сұрақтар.
- `src/art.js` — шартты SVG карталар, кеме, мұнай қимасы және құжаттар.
- `src/motion.js` — прокрутка, перспектива, сүйреу, үлкейту және бұру.
- `SOURCES.md` — тарихи деректер мен суреттердің шығу тегі.
- `REFERENCE_ANALYSIS.md` және `TOOLS.md` — бейнеталдау және құралдар.

ZIP архивіндегі `Ottoman_Atlas.html` файлын тікелей браузерде ашуға болады. Оны қайта жасау үшін алдымен `npm run build`, содан кейін `npm run offline` пәрменін іске қосыңыз. Дереккөздерге берілген сыртқы сілтемелерге интернет керек.
