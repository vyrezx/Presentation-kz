# Азамат соғысы жылдарындағы Қазақстан

**1918–1920 жылдар.** Қазақстан тарихы бойынша 8-сыныпқа арналған сегіз көріністі интерактивті таныстырылым. Тарихи хронология, архив суреттері және негізгі майдандардың сызба картасы қазақ тілінде берілген.

## Локальный запуск

Требуется Node.js 22.12+ или 24.x и npm.

```sh
npm install
npm run dev
```

Откройте адрес, указанный Vite в терминале. Для локальной проверки production-сборки выполните `npm run build`, затем `npm run preview`. Готовый статический сайт появится в `dist/`.

## Управление

- Прокрутка ведёт по сценам и позволяет пройти переходы в обе стороны. На широком экране задержитесь на сцене и прокрутите дальше, чтобы увидеть все события хронологии и карты.
- Клавиши ← / ↑ и → / ↓ переходят между сценами. Home ведёт к началу, End — к заключению. В меню «Мазмұны» можно выбрать любую сцену.
- Значок в верхней панели открывает полноэкранный режим в браузерах, поддерживающих Fullscreen API. Esc закрывает меню и окно источников.
- На карте можно нажимать метки и кнопки с названиями. В финале «Қайта көру» возвращает к вступлению, «Дереккөздер» открывает источники и атрибуцию.
- При системной настройке уменьшенного движения материалы идут в обычном порядке прокрутки. На узких экранах текст и фотографии располагаются последовательно.

## Тесты

```sh
npx playwright install chromium
npm run build
npm test
```

Если Chromium уже установлен, передайте его путь, например `CHROMIUM_PATH=/usr/bin/chromium npm test`. Playwright проверяет production-сборку и сохраняет скриншоты в `test-results/`.

## GitHub и Vercel

1. Распакуйте архив. Создайте пустой репозиторий на GitHub.
2. Загрузите содержимое папки `kazakhstan-civil-war/` в корень репозитория. Для загрузки через Git выполните из этой папки:

   ```sh
   git init -b main
   git add .
   git commit -m "Add Kazakhstan Civil War presentation"
   git remote add origin https://github.com/OWNER/REPOSITORY.git
   git push -u origin main
   ```

3. Откройте Vercel, выберите **Add New → Project** и импортируйте репозиторий GitHub.
4. Проверьте параметры проекта. Framework Preset — **Vite**, Build Command — `npm run build`, Output Directory — `dist`. Базовый путь `/` уже указан в Vite. Если исходники всё же лежат во вложенной папке репозитория, выберите её как Root Directory.
5. Нажмите **Deploy**. После сборки Vercel выдаст публичный адрес вида `project.vercel.app`. Git Integration будет публиковать обновления после push в production-ветку, а для остальных веток создавать preview deployments.

## Материалы и реализация

Сайт работает на React 19, TypeScript и Vite. GSAP Timeline и ScrollTrigger связывают монтаж с нативной прокруткой. Архивные WebP, шрифты и карта хранятся локально. Переходы используют открытие кадра маской, раздельный параллакс и сохранение фотографии между соседними сценами.

Исторический текст сверен с порталом «Қазақстан тарихы» и учебником Б. Абдуғұловой, А. Қапаевой и Г. Кенжебаева. Прямые ссылки на материалы и архивные оригиналы собраны в «Дереккөздер» и в `src/data/history.ts`. Отдельные общеисторические снимки отмечены соответствующей подписью. Схематичная карта показывает расположение ориентиров и условные направления без административных границ.

Noto Sans, Noto Sans Display и Noto Serif распространяются по SIL Open Font License 1.1. Файлы лицензий лежат в `public/fonts/`. Кадры референсов использованы для анализа монтажа. Раскадровка и сопоставление переходов приведены в [STORYBOARD.md](STORYBOARD.md).
