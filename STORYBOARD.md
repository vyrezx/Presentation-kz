# Режиссёрский план

Оба исходника — вертикальные записи экрана ноутбука, 576 × 1024. FFprobe показал 16,933 с для Antarctica и 16,000 с для Pear. Для первого прохода FFmpeg собрал контактные листы с шагом 0,5 с, для второго — крупные планы области экрана с шагом около 0,167 с. В дополнение FFmpeg проверил резкие изменения на каждом кадре. Плавные переходы разбирались по последовательности кадров на контактных листах. Время ниже относится к видео, а не к длительности анимаций сайта. Запись позволяет различить порядок и направление движения, но не исходные кривые, скорость прокрутки или реализацию эффектов.

| Фрагмент | Наблюдение |
| --- | --- |
| Antarctica ~0–1 с | Светлый крупный гротеск поперёк тёмного кадра, фото в центре, мягкий белый слой растёт снизу и заслоняет название. |
| Antarctica ~1–3 с | Светлое поле и небольшие текстовые островки. Горный массив приходит справа снизу и заполняет экран. |
| Antarctica ~3–6 с | Крупная фотография уступает место белому полю с центрированным антиквенным заголовком. Затем фотографии разных пропорций проходят полосой. |
| Antarctica ~6–9,5 с | Вертикальные полосы открывают новую фотографию. На общем фоне крупные панели движутся горизонтально с разными скоростями. |
| Antarctica ~9,5–12,5 с | Изображение занимает весь экран, крупные буквы проступают в нижней части, светлый проход ведёт к контрастной тёмной карте с тонкой линией маршрута. |
| Pear ~0–3 с | Антиква и текст слева, фигура и ткань справа на насыщенном поле. Крупный план ткани сменяют светлый кадр ветви и затем плотная листва. |
| Pear ~3–7,8 с | Плотный фон сменяется светлой асимметричной композицией. Камера приближает плод, половины расходятся, между ними разрастается синяя область с мягким краем. |
| Pear ~7,8–12 с | Цветовое поле с большим свободным пространством и коротким текстом справа. Крупный объект снизу слева и пространственные слои движутся в разном темпе. Светлая плоскость закрывает кадр. |

## Перенос в восемь сцен

| Сцена | Композиция и переход | Реализация |
| --- | --- | --- |
| 01 | Полноэкранный архивный кадр, белый крупный титр, светлая завеса снизу | Вложенные текстовые маски, stagger, масштаб фото и scrub для мягкой завесы |
| 02 | Молочный фон, текст слева, вокзал справа. Портал с вокзалом расширяется в следующий кадр | Полноэкранный фото-слой с анимируемым inset, камера внутри кадра, композиция текста уходит за фото |
| 03 | Крупный год и вертикальная линия с тремя датами рядом с архивным фото | Pin, шкала через scaleY, последовательное раскрытие записей, уход фото в полосы следующей сцены |
| 04 | Приглушённый красный и асимметричная расстановка трёх архивных кадров | Разнесённые маски, разнонаправленный parallax, разделённые полосы в начале |
| 05 | Тёмное поле с линиями путей, светлыми географическими ориентирами и короткими подписями | Схема без административных границ, масштаб карты, stroke-dashoffset, четыре интерактивные отметки |
| 06 | Широкая фотография на бумажном поле, меньший снимок со смещением, затем крупный план во весь экран | GSAP Timeline с параллаксом переднего слоя и раскрытием inset, завершающее совмещение с тёмным кадром |
| 07 | Тёмная фотография позади даты 1920, смена фона из центра | Камера через scale, большой год из маски, растущее мягкое окно теплого света |
| 08 | Светлое поле с кратким итогом, заголовком и архивным документом | Медленный разъезд текста и изображения, мягкая маска, доступный диалог источников |

Палитра из задания чередуется по монтажу. Узкий гротеск для вступительного титра и Noto Serif для редакционных заголовков различают два типографических регистра. Казахские буквы проверяются по локальным файлам шрифтов. Навигация отмечает текущую сцену и оставляет крупные композиции свободными. На портретных экранах информационные сцены читаются в естественном порядке, а фотопланы и переходы сохраняют контролируемое прокруткой движение. Режим уменьшенного движения оставляет все материалы доступными без закрепления сцен.
